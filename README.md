
# WorkLog

WorkLog is a personal productivity management application that helps users organize tasks, set goals, and track their progress through a centralized dashboard.

## Features

- **Dashboard:** Provides an overview of tasks, goals, and productivity statistics.
- **Task Management:** Create, update, and manage tasks with descriptions, categories, and deadlines.
- **Goal Tracking:** Set goals and monitor completion progress.
- **Journal:** Dedicated section for recording daily work and activities.
- **Analytics:** Track task completion, pending tasks, and overall productivity.

## Tech Stack

- **Framework:** Next.js
- **Frontend:** React.js
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Context API
- **Data Persistence:** Local Storage

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd worklog
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open `http://localhost:3000` in your browser.
